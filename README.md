# ARMUP AI 💪 — Deviens plus fort, à ton rythme

Application web (HTML/CSS/JS, sans dépendance ni serveur) de renforcement du haut du corps pour ados débutants, sans matériel.

- **Accueil** : programme du jour, temps de récupération, semaine, calendrier, exercices, badges.
- **Coach** : bilan de forme avant la séance (séance normale, allégée, mobilité ou repos), bibliothèque d'exercices avec personnage 3D animé, étapes, corrections de posture, séance guidée (séries, chrono, repos, auto-évaluation de la technique).
- **Programme** : 2 ou 3 séances courtes par semaine, toujours un jour de repos entre deux séances, explications sur la récupération.
- **Nutrition** : repas équilibrés, protéines, recettes halal, suivi de l'eau, sommeil. Aucun régime, aucun complément, aucun objectif de poids.
- **Progrès** : séances, régularité (graphique), technique, exercices appris, objectifs de force, badges, XP. Aucune comparaison physique.
- **Coach IA** : assistant conversationnel local (gratuit, hors ligne, aucune donnée envoyée) avec règles de sécurité pour ados.

Les données restent dans le navigateur (localStorage), sans inscription.

## Lancer

Ouvrir `index.html` dans un navigateur, ou servir le dossier :

```bash
python3 -m http.server 8000
```

Sur téléphone : héberger le dossier (ex. GitHub Pages) puis « Ajouter à l'écran d'accueil » dans Chrome.
